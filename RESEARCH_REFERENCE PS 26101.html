P1
Problem Deconstruction
Explain like I'm 15 · Root cause · Stakeholders · Why now

1.1 One-line Problem

India ke statistical officers ko aaj bhi training manually dhundni padti hai — koi system nahi jaanta ki us officer ka actual skill gap kya hai, kaunsa course sahi hai, aur uploaded PDF/PPT se quiz kaise banega. AI se gap identify karo, iGOT se connect karo, uploaded material se MCQ auto-generate karo.

1.2 Example — Priya, 28, JSO

STORY
Priya Lucknow mein JSO (Junior Statistical Officer) hai, NSSO mein. Naya PLFS (Periodic Labour Force Survey) aaya hai — usse sampling design revise karna hai. Woh iGOT Karmayogi par login karti hai: 5,600+ courses. "Sampling" search karti hai → 30 results. Kaunsa sahi hai uske role ke liye? Platform nahi jaanta. Uska senior ek naya 3-lecture ka PDF circular bhejta hai — team ke liye quiz kaun banayega? Koi auto-system nahi hai. Yehi problem hai.

1.3 Real Problem

  • Statistical workforce badal raha hai: Excel/paper surveys se Python, R, ML, geospatial, big data tak.
  • Training static hai: NSSTA classroom (Greater Noida) saal mein kuch batches — continuous upskilling ke liye insufficient.
  • iGOT generic hai: courses sabke liye same — "Karmayogi Officer" ke liye, MoSPI-role-specific nahi.
  • Skill mapping missing: supervisor ko nahi pata team kahan weak hai. Assessment manual. Material (PDFs/circulars) alag rehta hai, quizzes alag.

1.4 Root Problem 4 root causes, not one

🔀 Fragmented Framework

MoSPI ke paas role-level granular competency dictionary nahi — FRAC generic hai.

🎓 Learning ≠ Job

iGOT par mapping/recommendation logic shallow — course lerka role se match nahi hota.

📉 No Data Flywheel

Supervisor ko visibility nahi: kisne kya seekha, kahan weak hai → manual reporting.

📄 Material→Assessment Gap

Circulars/PDFs aate hain, par auto-assessment zero.

India-Specific Landscape
iGOT · NSSTA · MoSPI · players
✅ ALREADY EXISTS

FRAC framework (DoPT) · iGOT course marketplace (5,600+) · AI Tutor/Sarthi (basic) · subtitles 11 langs · multi-stakeholder dashboards · APAR linkage mandate.

⚠️ PARTIALLY SOLVED

Skill-gap ID (nascent) · course recommendation (generic) · multilingual · workforce analytics (basic) · coding sandbox (hints only).

❌ UNSOLVED

MoSPI-specific competency ontology · document→MCQ from circulars/PPTs · coding sandbox for stats · predictive competency forecasting · adaptive difficulty · real-time APAR competency · sectoral deep layer below iGOT.

🔗 INTEGRATION + AI + UX GAPS

No reference vertical in iGOT. AI = operational (moderation/tags), not transformative. UX = government-portal-plain (judges: "feels 2014").

KEY INSIGHT
iGOT is horizontal; PS 26101 asks for a MoSPI vertical. Integration gap = opportunity. A demonstrably-better ministry vertical is exactly what Mission Karmayogi needs as reference implementation.

Why hasn't this been solved?

  • iGOT horizontal by design — verticals must be built separately (Tarento case study).
  • Govt procurement cycles slow (5-7 yr RFPs).
  • Public-sector AI needs explainability + safety.
  • Statistical domain niche — commercial AI vendors ignore it.
  • Attrition crisis only surfaced 2024-26.
  • "Coding sandbox for statistical officers" = bespoke requirement.
